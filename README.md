## 📘 Overview

This project aims to build a **Fake News Detection Model** that classifies news articles as *Fake* or *True* using **TF-IDF vectorization** and **Logistic Regression**.  
It demonstrates an end-to-end **machine learning pipeline** — from data loading and text cleaning to model training and evaluation.

---

## ⚙️ Features

✅ Load and combine real and fake news datasets  
✅ Clean and preprocess textual data (punctuation, stopwords, case normalization)  
✅ Convert text into numerical features using **TF-IDF**  
✅ Train a **Logistic Regression** classifier  
✅ Evaluate using accuracy, precision, recall, and confusion matrix  
✅ Provide an **interactive prediction interface** for new articles
